저장소 연결

비공개 저장소는 GitHub 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고 api.github.com 외에는 보내지 않습니다. 주소 끝에 ?repo=조직/저장소를 붙이면 그 저장소가 미리 채워집니다.

토큰 만들기
  1. Fine-grained 권장: GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Resource owner = 조직명, Repository access = 이 저장소만, Permissions → Issues: Read-only (Metadata는 자동 포함). 조직 정책상 관리자 승인이 필요할 수 있습니다.
  2. Classic 토큰을 쓰면 repo 범위가 필요하고, 조직에 SAML SSO가 걸려 있으면 토큰 목록에서 Configure SSO → Authorize를 눌러야 합니다.
